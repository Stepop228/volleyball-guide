# Волейбол для начинающих

Информационно-справочный сайт о базовой технике волейбола: стойка и перемещения,
передачи, подачи, нападающий удар, блок, защита и краткие правила игры.

Проект рассчитан на любителей и новичков, которые только начинают знакомиться с волейболом.

## Структура

```
.
├── index.html        # основная страница со всеми блоками
├── css/
│   └── style.css     # нейтральная базовая тема, палитра в CSS-переменных
├── js/
│   └── main.js       # меню, подсветка раздела, кнопка «наверх», аккордеон
└── README.md
```

## Запуск

Сайт статический — достаточно открыть `index.html` в браузере.
Для локального сервера можно использовать, например:

```bash
python -m http.server 8000
```

и открыть `http://localhost:8000`.

## Содержание

- **Основы** — стойка волейболиста, перемещения и остановки.
- **Приёмы с мячом** — передача сверху, приём снизу, нижняя и верхняя подача.
- **Атака и защита** — нападающий удар, блок, страховка.
- **Правила** — три касания, ротация, набор очков.
- **Словарь** — короткие определения основных терминов.

## Дизайн

Оформление намеренно нейтральное: светлый фон, сдержанная палитра, один акцентный
цвет. Все ключевые значения вынесены в CSS-переменные в начале `css/style.css`,
поэтому тему легко перекрасить без переписывания вёрстки.
