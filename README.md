# Создание интерактивного сайта для помощи начинающим волейболистам с помощью нейросети OpenCode

Информационно-интерактивный справочник по базовой технике волейбола: стойка и перемещения,
передачи, подачи, нападающий удар, блок, защита, краткие правила игры и словарь терминов.

Проект рассчитан на любителей и новичков, которые только начинают знакомиться с волейболом.

**Сайт:** https://stepop228.github.io/volleyball-guide/
**Исходный код:** https://github.com/Stepop228/volleyball-guide

## Что внутри

- **6 разделов:** Основы, Приёмы с мячом, Атака и защита, Правила, Словарь, Теория и источники.
- **10 карточек элементов:** пошаговая инструкция, частые ошибки, совет и блок безопасности.
- **Словарь** из 12 терминов.
- **Раздел «Теория и источники»:** ключевые цифры правил, история игры по годам, сравнение
  похожих ресурсов, список учебников и прямые ссылки на официальные правила 2025—2028.

## Как это сделано

- HTML, CSS и JavaScript — без внешних библиотек и фреймворков.
- Раскрывающиеся карточки — на встроенном элементе `details`, поэтому работают даже без JavaScript.
- Подсветка активного раздела — через `IntersectionObserver`.
- Вся палитра вынесена в CSS-переменные: тема перекрашивается в несколько строк.
- Материалы собраны с помощью ИИ-агента **OpenCode**, каждый факт проверялся по указанным источникам.

## Структура


## Запуск

Сайт статический — достаточно открыть `index.html` в браузере.
Для локального сервера можно использовать, например:

```bash
python -m http.server 8000
```

и открыть `http://localhost:8000`.

## Содержание

- **Основы** — стойка волейболиста, перемещения и остановки.
- **Приёмы с мячом** — передача сверху, приём снизу, нижняя и верхняя подача.
- **Атака и защита** — нападающий удар, блок, страховка.
- **Правила** — три касания, ротация, набор очков.
- **Словарь** — короткие определения основных терминов.
- **Теория** — цифры правил, история игры, обзор аналогов и источники.

## Дизайн

Спортивная палитра: глубокий синий (цвет волейбольного мяча) как основной цвет и солнечно-жёлтый
как акцентный, светлый фон и белые карточки с мягкими тенями. Все ключевые значения вынесены в
CSS-переменные в начале `css/style.css`, поэтому тему легко перекрасить без переписывания вёрстки.
